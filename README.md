# Maze Craze
Maze Craze is a game which requires some patience in navigating through the maze to collect coins. Collect coin and teleport to the other part of the map to complete the level, but beware of the hazards!

# Description
This game requires player to move around the maze and find their way till the reached the exit!. Players are required to collect the coins placed in the maze. However there will be hazards placed around the maze! Hitting it will make you lose the score. Making the score till it reaches 0, will make the player restart the level.

# Dependencies
Game can only be played on Windows Operating System.

# Controls
- W = Forward
- A = Left
- S = Backward
- D = Right
- Shift = Run 
- Spacebar = Jump
